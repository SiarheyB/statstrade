# «Точка входа» — что осталось (2026-09-06/09)

Снимок на конец сессии с банками игроков и фиксом чата. Порядок — по тому,
что сказал пользователь и что осталось недоделанным по факту кода, а не по
памяти.

## Явно запрошено, ещё не сделано

1. **История сделок на графике в стиле MT5**, включая сделки ботов —
   пункт 6 из восьмипунктового списка фидбека. Не начато: сейчас на графике
   есть только SL/TP/трейлинг текущей позиции (см. `PriceChart.tsx`), нет
   слоя с прошлыми входами/выходами (своими и чужими).

## Обсуждали, решение есть — осталось реализовать

2. **Закрытость банка.** Договорились: у центробанка данные остаются
   публичными (это регулятор, к нему у всех должно быть доверие через
   прозрачность), а у банков игроков наружу должны идти только капитал и
   балансовая стоимость бумаги — без разбивки на детали. Сейчас `/api/game/
   userbank` и так не раскрывает чужие банки (только свой), а публичный
   листинг (`allListings()`) отдаёт `capital`/`bookValuePerShare` — то есть
   по факту уже соответствует решению. Стоит явно перепроверить, что нигде
   (например, в будущей карточке банка на бирже) не всплывут держатели
   облигаций или сумма займов — только когда такая карточка появится.

## Известные технические долги

3. **Флаки `auction.test.ts`** — изредка падает только в полном
   параллельном прогоне (`npx vitest run` всех файлов сразу), в одиночном
   запуске стабилен. Похоже на состояние гонки между тестовыми файлами,
   трогающими общий `GameBank`/`GameRepossessed` — не диагностировано до
   конца.
4. **Новости только на русском.** Шаблоны `newsEngine.ts` — русские; в
   английской локали лента всё равно русская. В `NewsEvent` уже есть
   `templateId`/`subject`, англоязычный файл шаблонов подставится без
   потери уже вышедших новостей — просто ещё не написан.

## Не начато (Фаза 6 по исходной спеке, дальний горизонт)

5. Опционы.
6. Конструктор алгостратегий для игрока (не путать с ботами — это
   пользовательский DSL/визуальный билдер).
7. Арбитраж между инструментами/биржами.
8. Полноценный маркет-мейкинг от лица игрока (сейчас маркет-мейкер — это
   бот-движитель рынка, не роль, доступная игроку).
9. Лицензии и полное дерево навыков (Фаза 4 по спеке) — сейчас есть только
   контракты-испытания и перки, не полноценные лицензии по направлениям.

## Отложено осознанно

10. **Android APK** — по решению пользователя, только после того как
    веб-версия полностью устроит. Не начато и не планируется раньше этого.

## Идеи на будущее (не запрошены явно, всплыли по ходу работы)

- Карточка банка игрока на бирже (клик по тикеру `NRTH`/`NRTHB` → отдельная
  страница с капиталом, балансовой стоимостью, но без деталей — см. пункт 2).
- Банкротство банка игрока: сейчас нет сценария, что будет с акциями/
  облигациями, если владелец обанкротится или банк потеряет весь капитал.
  Стоит продумать до того, как это случится с первым банком в проде.
- Вторичный рынок для низколиквидных бумаг банков игроков — если бумага
  почти не торгуется, размещение по «биржевой» цене может давать случайные
  выбросы (мало сделок = дёрганая цена). Стоит последить в проде.
